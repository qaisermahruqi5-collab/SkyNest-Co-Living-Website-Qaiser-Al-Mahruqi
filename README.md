# SkyNest Co-Living Website

Website for SkyNest Co-Living Spaces, made by Qaiser Al Mahruqi for BTEC Level 3 IT Unit 6: Website Development.

## Links
- GitHub repository: https://github.com/qaisermahruqi5-collab/SkyNest-Co-Living-Website-Qaiser-Al-Mahruqi.git

## Pages
- `home.html` – Home
- `about.html` – About
- `services.html` – Services and packages
- `portfolio.html` – Gallery
- `contact.html` – Contact and enquiry form

## Files
- `css/style.css` – all the styling
- `js/script.js` – mobile menu and enquiry form validation
- `images/` – compressed WebP photos and icons

Open `home.html` in a browser to view the site.
